# SHA-256 模块

## 概述

`lib/sha256/` 提供 SHA-256 哈希工具，约 50 行 Go 代码。主要是对 `crypto/sha256` 的薄包装。

## 职责

- **哈希计算**：计算数据的 SHA-256
- **流式哈希**：支持流式数据

## 函数

### Sum256

```go
func Sum256(data []byte) [32]byte {
    return sha256.Sum256(data)
}
```

### New

```go
func New() hash.Hash {
    return sha256.New()
}
```

## 使用场景

- 文件块哈希（`lib/scanner/`）
- 设备 ID 计算（`lib/protocol/deviceid.go`）
- 证书指纹

## 性能

- 使用 `crypto/sha256` 标准库
- 支持硬件加速（如 Intel SHA-NI）
